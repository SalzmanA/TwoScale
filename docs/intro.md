## The TwoScale library

This is a presentation of the distributed two-scale method introduced in {cite:t}`Salzman_2023_1` from the seminal work of {cite:t}`Duarte2007` and adapted for use with FEniCSx/PETSc. 

The method part gives some hints on the theoretical basis ({ref}`theo`), how the method can be used with the FEniCSx/PETSc libraries ({ref}`plug`) and in {ref}`DBCinTSALG`, an explanation of how Dirichlet boundary conditions are set at the coarse scale.

In Tutorials part some examples of problems solved with the two-scale method are given as notebooks to become familiar with the implemented library. Some are step-by-step example.

Finally, in the API part, you will find {ref}`Python` and {ref}`C++` documentation of the TwoScale library.
