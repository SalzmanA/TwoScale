## The Two Scale library

This is a presentation of the distributed Two scale method introduced in {cite:t}`Salzman_2023_1` from seminal work of {cite:t}`Duarte2007` and adapted to FEniCSx/PETSc usage. 

The method part give some hints on the theoretical bases ({ref}`theo`), how the method can be introduced in FEniCSx/PETSc libraries ({ref}`plug`) and in {ref}`DBCinTSALG` an explanation on how Dirichlet boundary conditions are set at coarse scale.

In Tutorials part some examples of problem solved with the  Two Scale method are given as notebook to get familiar with the implemented library. Some step by step.

Finally in API part you will find {ref}`Python` and {ref}`C++` detailed documentation of the Two Scale library.
